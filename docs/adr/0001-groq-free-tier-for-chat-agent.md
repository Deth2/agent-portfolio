# Usare Groq (free tier) invece di Claude/OpenAI/Ollama per l'agent chat

Il portfolio è un progetto personale a basso traffico e deve restare a costo zero. Claude e OpenAI hanno tier gratuiti minimi o assenti per uso continuativo; Ollama girerebbe gratis ma richiede un demone sempre acceso con GB di RAM, incompatibile con le funzioni serverless stateless di Vercel (limiti di ~60s di esecuzione, 1GB RAM, 50MB di deploy) — ospitarlo altrove (Railway, Fly.io, VPS) reintrodurrebbe un costo fisso. Abbiamo scelto **Groq** (Llama 3.3 70B via API HTTP compatibile OpenAI): nessun hosting di modelli da gestire, tier gratuito ampio (1000 richieste/giorno), velocità elevata, qualità sufficiente per rispondere su un singolo CV. Rischio accettato: i tier gratuiti dei provider LLM non sono garantiti a vita e potrebbero cambiare condizioni in futuro.
